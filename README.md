# Exiles Atlas

Offline-first second-screen companion for Conan Exiles.

## Scope

- Interactive map and player marker
- POI categories and discovery state
- Gatherables, treasures, chests, weapons, relics, bosses, and events
- Recipes and personal notes
- Optional live-position integration through an authorized mod/server bridge

## Development rules

- Do not scrape proprietary map websites without permission.
- Do not read or modify Conan Exiles process memory.
- Keep live tracking opt-in and clearly indicate stale or unavailable data.

## Planned stack

- Tauri
- React
- TypeScript
- MapLibre
- SQLite
